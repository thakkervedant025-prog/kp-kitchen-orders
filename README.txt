K.P.'s Kitchen Customer Order Dashboard

Files: index.html, style.css, script.js, orders.json
Orders imported from the 7Nov Bulk and 7Nov Tiffin sheets (76 orders).
Manager password: 2710

To use: publish this repository with GitHub Pages, then open the site. Select a customer to view their order. Manager login enables changing status between New and Complete.

Privacy: delivery addresses, phone numbers, email addresses and other contact fields have been removed from the uploaded order data. Customer names, order items and totals remain visible in this public repository.

Status storage: this static version saves status in localStorage in the browser/device used to update it. It does not sync across different devices or browsers. Shared live status requires a database/backend.
